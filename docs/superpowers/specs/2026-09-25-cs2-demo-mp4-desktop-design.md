# CS2 Demo 本地 MP4 导出工具：第一版设计

日期：2026-09-25；2026-09-26 按最新开发要求修订。实机验证状态以 [技术 Spike](../../SPIKE-CS2-HLAE.md) 为准。

## 目标

让用户在比赛结束后导入 CS2 demo，点选自己的第一人称视角，在桌面 App 内预览并选取起止点，再由 App 自动回放与渲染，得到正常游戏画面的 MP4。导出视频保留常规游戏 HUD，不包含 demo 控制台、播放栏或 App 界面。比赛进行时无需录屏。

产品为 Windows 10 1903 及更新版本、Windows 11 的本地便携软件。无需产品账号、云数据库或部署服务。CS2 和 Steam 由用户自行安装；首次使用时定位 CS2、HLAE 与 FFmpeg，之后记住路径。应用运行期间不上传 demo 或视频。

## 第一版范围

- 导入本地 `.dem` 或包含单个 `.dem` 的 ZIP。以用户提供的完美平台样本为首个验收样本；已确认它包含 `PBDEMS2` 格式的 CS2 demo。样本及其文件名不进入公开仓库。
- 解析地图、回合、时间范围和玩家列表。用户从列表中点选自己，应用保存所选玩家标识。
- App 内显示真实 CS2 第一人称预览。时间轴可拖动，支持播放、暂停和开始/结束标记；实际跳转允许有加载等待，不伪装为已预渲染视频。
- 导出前可选原始天空、已验证的天空预设及颜色调整，X 光开关，以及关闭、仅队友、仅对手、双方四种语音模式。语音模式只在 demo 包含对应语音时可用；缺失时禁用并说明。
- 输出本地 MP4，默认 1920×1080、120 FPS、High 画质、H.264 视频与 AAC 音频；另提供 30/60/144/240 FPS。用户可选择保存目录。导出进度和失败原因在 App 内显示。各档只能在实际验收后宣称支持。
- 项目、导入文件引用、所选玩家、片段范围、视觉与语音设置、输出目录和导出记录保存在便携目录的 `data` 子目录，关闭和重启后恢复。
- 发布应用源码和 Windows 便携下载包。应用自有代码采用 MIT 许可；第三方软件以各自许可和官方获取渠道独立提供。

## 暂不包含

5E demo 的已验证兼容性、自动挑选精彩片段、任意第三方场景贴图导入、其他玩家 POV、手机端、云同步、在线账号、批量渲染和无需 CS2 的独立 3D 渲染器。5E 样本到手后再加入兼容性验证，不预先宣称支持。

## 方案与取舍

1. **选定方案：CS2 实时预览并对选中片段离线渲染。** 保留原游戏画面，避免整场预渲染；依赖本机 CS2 和与当前游戏版本匹配的 HLAE。拖动时间轴后可能需要等待 demo 跳转。
2. **整场预渲染代理视频。** 时间轴拖动更顺滑，但首次导入慢、占用大量空间，修改天空或 X 光后还要重新渲染。
3. **自行重建游戏画面。** 可以不启动 CS2，但需要重做地图、材质、动画和音效，无法合理保证与原游戏画面一致；不适合第一版。

## 组件边界

- **桌面界面：**负责导入、项目列表、第一人称预览、时间轴、设置和导出状态。采用已在对话中审阅的左侧导入、中间预览与时间轴、右侧设置布局；草图中的地图、玩家和时间均为示意值。
- **Demo 索引器：**只读打开 ZIP/DEM，校验格式并提取玩家、地图、回合、事件和 tick 到时间的映射；返回结构化索引，不驱动游戏。ZIP 解压到应用临时目录，不能覆盖用户文件。
- **CS2 会话控制器：**定位游戏与 HLAE，检查现有 CS2 进程，以隔离配置、窗口模式、`-insecure` 启动制作专用实例；加载 demo、定位玩家、暂停和跳转。控制命令仅发给本机该实例。第一项工程验证必须证明可稳定从 App 控制当前版本的 CS2；验证未通过时不继续制作导出流程。
- **预览适配器：**按窗口捕获 CS2 的游戏画面并显示在 App 中。第一项工程验证同时检查捕获不是黑屏、控制台画面不会进入预览，以及预览和时间轴位置相符。预览帧不作为最终输出。
- **渲染器：**根据项目设置生成有边界的导出任务，在指定 tick 区间应用天空、X 光、视角和语音设置，调用 HLAE 录制与 FFmpeg 编码；只在视频完整可播放且音画时长符合范围后，将临时文件原子性移到目标 MP4 路径。
- **本地项目存储：**保存项目数据、依赖路径、任务状态和错误日志。demo 和 MP4 不复制进数据库；记录原路径及文件指纹，源文件移动或改变时要求重新定位。

## 用户流程

1. 首次启动：检查便携目录可写、Steam/CS2、HLAE、FFmpeg、磁盘空间。能自动发现的直接使用，未发现的引导用户选择本地路径；不在 App 内静默联网下载。
2. 导入：选择 ZIP/DEM，校验单个 CS2 demo 后解析索引。ZIP 条目路径需限制在临时目录内，避免路径穿越。
3. 预览：用户点选自己的玩家，App 启动制作专用 CS2。左侧显示 demo 与玩家，中间显示游戏预览和时间轴，右侧提供天空、X 光、语音、MP4 设定。
4. 选段：拖动播放位置和入/出点，精确范围以 demo tick 存储。界面显示对应时间；导出前校验开始早于结束且视角在该片段内可用。
5. 导出：应用复位回放、按设置重新渲染片段，写入临时目录，校验完成后输出 MP4。记录成功或失败，不删除原始 demo；关闭 App 后仍可查看项目设置与输出位置。

## 安全与失败处理

- 不编辑 `GameInfo` 或 Steam/CS2 安装目录内的原有配置；制作配置放在应用目录中，与正常游玩配置隔离。
- HLAE 仅用于 demo 制作实例；启动参数包含 `-insecure`。若已运行普通 CS2 实例，先要求用户关闭它。App 不提供连接服务器的入口，也不宣称零风险。
- 依赖版本不匹配、demo 无法加载、预览黑屏、跳转失步、语音不存在、空间不足或录制超时，均应给出具体错误；不得显示“导出成功”或留下目标路径上的半成品 MP4。
- 原 demo、正常游戏配置和既有 MP4 均不被覆盖。临时文件只在用户可见的任务结束或明确清理时删除。
- CS2 更新可能使 HLAE 或控制接口失效。启动前检查版本，失败时停止任务并提供诊断信息，不尝试自动修改游戏文件。

## 验收与工程验证顺序

1. 用完美平台样本验证 ZIP/DEM 解析、玩家列表、回合时间线和项目重启恢复。样本仅留本机，不提交到开源仓库。
2. 在当前本机 CS2/HLAE 版本上验证自动启动、只连本机的回放控制、玩家第一人称锁定、时间轴跳转和 App 内窗口捕获。若该阶段不稳定，先向用户报告并重新评审方案。
3. 导出约 10 秒的 MP4，检查视频可播放、无 demo 控件、常规 HUD、选段起止与音画同步。随后逐项验证天空预设、颜色调整、X 光和可用语音模式。
4. 重启 App 后复查项目与设置，模拟缺少依赖、源文件移动、磁盘不足和中途退出，确认错误提示与文件保护。
5. 在干净的 Windows 10/11 环境测试便携包的首次设置、离线运行及开源依赖声明。5E 样本到手后另行验收，不计入当前首版通过条件。
